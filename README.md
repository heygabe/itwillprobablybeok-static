# It Will Probably Be OK – Static Archive

This repository preserves the **It Will Probably Be OK** website and its recordings for posterity. It was originally hosted on Fireside.fm, which provided a “Haiatus” feature that kept the site online indefinitely. Since that platform is not a static site and isn’t directly editable, this archive captures the entire site as static HTML files, allowing it to be hosted forever (e.g., via GitHub Pages).

## Why this archive exists

1. **Vibe‑coded git repository** – The project is a curated snapshot of the original site, version‑controlled for easy updates and preservation.
2. **Preservation of content** – I want to ensure the recordings, articles, and other media are not lost if hosting payments cease.
3. **Love for Fireside.fm** – Fireside was an awesome platform. Its “Haiatus” feature kept the site alive, but because it isn’t a static, editable site, I’m creating a permanent, static copy.
4. **Enjoy the archive** – Despite the inevitable heat death of the universe, feel free to explore and enjoy this preserved content.

The site is ready to serve as‑is. You can host it on any static‑file server (e.g., GitHub Pages). The `main` branch is automatically published to GitHub Pages; changes typically appear within a few minutes after a push.
